# 安装与回滚边界

安装前核对已支持机型、固件、主用户、启动校验状态、八个系统文件、系统互传包、入口和开关键。包内 APK 必须匹配固定摘要。缺少的组件才会安装，已有匹配版本会复用；未知版本或使用者已停用的组件不会被替换或启用。

`--engine-only` 模式只安装和授权原厂互传，不安装、授权、更改或卸载快捷入口。没有附带入口 APK 的精简包默认选择此模式。精简版可通过电脑直接打开原厂设置。

安装器补齐所选应用所需的权限，并按 UID 授予原厂互传所有文件访问。原有授权不重复写入，原有单包文件访问模式不变。设备名仅在无值时填入 PZ261A。悬浮和实况通知、按钮布局由使用者在手机页面完成。

状态写入 `.local-state/`，绑定所选设备，不覆盖首次基线，不进入分享包。安装、授权和配置开始前记录计划。安装中断时，请保留原状态，先回滚，再保存旧状态副本后进行下一次安装。

## 回滚

1. 仅还原工具直接写过、且当前仍等于记录值的键。后来自行修改的设备名保留。
2. 仅撤销本次新授予的权限。应用已被其他版本替换时跳过；涉及原厂权限时先停止原厂应用。
3. 恢复工具修改、应用内容未变且当前仍匹配的所有文件访问 UID 模式，不动原单包模式。
4. 只卸载工具新安装且摘要仍匹配的快捷入口，不卸载预先存在或后来替换的应用。
5. 默认保留原厂互传。首次回滚时加 `--remove-engine` 才卸载工具新安装且内容未变的原厂互传。卸载会清除其私有数据。
6. 工具不清理共享下载文件，不重置手动通知选项，不关闭蓝牙或 WLAN。

同意状态、开关、时间戳、初始化配置及系统通知支持列表等由原厂或系统自行产生，不承诺全部自动恢复。回滚只撤销工具记录的改动。同一状态完成回滚后不能重复使用，首次回滚时就应决定是否移除原厂互传。丢失状态后，不用猜测值代替原始基线。

## 主机支持

Linux 使用 `sh ./install.sh`，macOS 使用 `install.command`，Windows 使用 `install.bat`。安装、检查、打开设置和回滚共用 Python 工具。主机需要自己的 adb；Linux USB 权限由发行版的 udev 和用户组规则管理，详见 README。
